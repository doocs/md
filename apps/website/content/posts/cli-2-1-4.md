**@doocs/md-cli 2.1.4** 于 **2026 年 10 月 30 日** 发布。本文根据该次正式发布和 CLI 更新说明整理。

## 本次变化

CLI 通过 Changesets 自动化管理版本、生成更新说明并发布到 npm。对应改动可查看 [PR #2001](https://github.com/doocs/md/pull/2001)。

## CLI 的用途

CLI 用于在本机启动编辑器服务，由浏览器访问 Web 编辑器。它不是批量将 Markdown 文件转换为输出文件的命令。

安装和启动方法请查阅 [CLI README](https://github.com/doocs/md/blob/main/packages/md-cli/README.md)。

## 与主项目分开记录

CLI 使用自己的 npm 包版本与标签。主项目的 v2.1.0 和 CLI 的 2.1.4 代表不同发布渠道，不应把 CLI 的最新版本号当作主项目版本号。

[更新日志](/changelog/)提供主项目与 CLI 筛选，每个版本保留原始发布链接。
