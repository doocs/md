主题决定整篇文章的排版，组件用于插入可复用的内容。MD 的市场围绕这两类作品组织。

## 预览和安装主题

在编辑器中打开社区主题市场，先通过预览查看文章效果，再安装作品。安装后，主题可以应用到文章，并继续调整字体、颜色、间距等设置。

![社区主题市场与文章预览](/images/market-light.webp)

内置的经典、优雅、简洁主题也可以作为起点。需要更细的样式控制时，使用 CSS 编辑器创建自己的方案。

## 插入组件

组件安装后会加入自定义组件列表。选择组件、填写参数，再将结果插入文章。组件适合作者信息、提示块等重复使用的内容。

使用组件后仍应检查文章预览与公众号后台效果，尤其是包含图片、外链或较复杂布局的组件。

## 发布自己的作品

发布主题或组件需要登录，并提交审核。通过审核后，社区可以预览和安装作品。发布频次受服务端账户配额约束。

作品说明应写清用途、参数和必要的使用条件。不要在主题 CSS、组件示例或说明中包含密钥等个人配置。

## 分享与备份

主题 CSS 和组件文件可以导出，便于备份、跨设备导入或直接分享文件。社区发布与文件分享是不同的使用方式。

如果只想统一自己的排版风格，先保存一个 CSS 方案即可；需要让其他人发现和安装时，再考虑提交到市场。
