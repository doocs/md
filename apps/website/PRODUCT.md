## Platform

web

## Product Purpose

Introduce doocs/md and direct visitors to the existing editor at https://md.doocs.org.
The user confirmed a separate apps/website workspace and a homepage-first scope.

## Users

Content creators preparing Markdown articles for WeChat public accounts, as described in the repository README.

## Capabilities and Constraints

Product facts come from the md README: Markdown rendering, themes, custom CSS, diagrams, image hosting, AI assistance, local drafts, cloud preferences, and multiple editor integrations.
The homepage must not replace the existing editor. Documentation links use existing published documentation and repository files.
This first version is in Simplified Chinese; documentation migration and deployment are open decisions.

## Brand Commitments

Adapt the Tabularis website's existing visual system and homepage composition, as requested and confirmed by the user. Use md branding and product content.
